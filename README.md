# 循序 · 算法学习管理

一个本地管理面板，配合当前项目里的聊天教练使用。它读取你已有的进度和日志，管理每日任务、间隔复习、题目状态、限时模拟与能力周报，并根据你的学习画像推荐题目、调整指导方式。

## 个人学习画像与个性化推荐

左侧 **我的画像**。所有结论都来自你的练习记录和你自己设定的目标，不改动记录：

- **专题掌握度**：按练习结果计分（独立完成 1、提示后完成 0.4、未完成 0），越近的练习权重越高（半衰期 30 天），并做平滑，记录少时不会给出极端值；有结果的练习少于 2 次显示“起步”。其他档位为“需要加强”（低于 50%）、“巩固中”（50%～74%）、“较稳”（75% 及以上）。
- **反复错因**：近 4 周至少两次、或 7 天内刚出现的错因，附写代码前该问自己的问题和证据。
- **习惯**：近 4 周的练习次数、独立完成率、提示依赖、计时、连续打卡和限时模拟。
- **我的目标**：面试日期（倒计时）、每天计划学习时间、节奏偏好（稳扎稳打 / 正常推进 / 冲刺加速），点“设置学习目标”修改。今日页的时间档默认跟随这里的每日计划时间。
- **给你的建议**：按画像生成接下来的重点；点 **让 AI 分析我的情况**，用已连接的模型生成一份阶段建议（只发送画像和今日计划，不发送代码；未连接时按固定规则生成）。结果保存在本机 `.runtime/profile-advice.json`。

**新题自动推荐**：待学队列不足时，空余的新题名额按画像自动补进今日计划，标为“为你推荐”，每道都写明理由。推荐综合：

| 因素 | 怎么影响推荐 |
| --- | --- |
| 主线位置 | 当前专题还没稳时，先在当前专题巩固；已较稳时，推进到主线下一专题 |
| 专题掌握度 | 已学专题里掌握度低的，补一道同专题题 |
| 反复错因 | 优先能练到同一解题模板的题，并保证推荐里至少有一道 |
| 难度匹配 | 起步 / 需要加强偏 Easy，巩固中偏 Medium，较稳可以挑战 Hard；提示依赖高时少推 Hard |
| 节奏偏好 | 稳扎稳打少推 Hard，冲刺加速多推 Medium 和高频 Hard |
| 目标日期 | 离面试 8 周以内时优先大厂高频题 |

不合适就点 **换一题**（7 天内不再推荐），想长期保留就 **固定加入待学**。校准旧题仍然在待学不足时占 1 个名额。工作台保存结果后，提示框会给出下一题，点“去练习”直接切过去。

**个性化指导**：教练对话和智能体的提示词会带上这道题所属专题的掌握度、可能在本题出现的常见错因、提示依赖和节奏偏好，据此调整追问深度，并在合适的时候用对应的问题提醒；模拟面试时不使用画像。离线引导的“检查我的讲解”也会优先追问你常犯、且可能出现在本题的错因。

命令行：`python tools/coach.py profile` 查看画像，`profile --target-date 2026-12-01 --minutes 120 --pace normal` 设定目标，`new skip 75` 换掉推荐。

## 第二轮新增

- **会解释的每日排题**：复习不再只按最早到期日排序，而是综合逾期天数、上次是否需要提示、近期反复错因、与当前专题的衔接、久未练习专题的轮换，每道题都写明理由。积压的复习会显示按天消化的估计；选 180 分钟时多安排 1 道复习。待学不足时，用 1 个名额安排“校准”旧题（不计作新题），其余名额按学习画像自动推荐新题（见上一节）。理由只说明为什么排这道题，不透露解法。
- **限时模拟面试**：左侧“模拟面试”。可抽题（开始前不显示题目）或指定题目，限时 15～45 分钟。流程是讲思路 → 写代码并运行本地用例 → 回答边界追问和延伸追问 → 五维自评（题型识别、沟通表达、代码正确性、复杂度分析、时间控制）。用时以本机服务记录的开始时间为准，刷新页面不会重置；用时和代码正确性会自动给出建议分。求助或看提示后按“提示后完成”记录。保存后记为一次限时训练，并按真实结果安排复习。
- **能力周报**：原“每周复盘”。对比本周和上周的学习日、独立完成率、平均用时和限时模拟次数，展示五维评分（最近一次与近 4 次平均）、近期反复错因及之后是否已独立完成、“先卡住、后独立完成”的进步证据、专题进度，并自动生成“下周重点”。可以导出 Markdown。缺少的数据会写在“数据说明”里，不做推断。旧格式记录没有逐次结果，按进度表状态推断并单独计数；历史补录不计入独立完成率。
- **网页教练对话**：工作台和模拟面试里都有对话面板，按钮包括“检查我的讲解”“给我一层提示”“帮我看代码”“复盘总结”，也可以直接提问题意或 Python 写法。默认**离线引导**：按费曼步骤追问，提示就是分层提示，不发送任何数据。在“教练设置”里可以连接 OpenAI 兼容接口（GPT，例如自建 CPA）或 Claude，必须点击“测试并启用”且测试成功才会生效；连接后，这道题的题意、你的草稿和代码、本轮测试结果和这道题的练习记录会发送给模型。以下情况都会计为提示，完成时按“提示后完成”记录：模型给出的提示、本地用例通过前请教练定位错误、自由提问中模型给出了解题方向。
- **题库扩充**：候选新题目录共 78 道，覆盖双指针、滑动窗口、链表、哈希、字符串、栈与队列、二叉树、回溯、贪心、动态规划、二分、堆、图论。工作台本地用例从 47 道增加到 79 道（245 组基础用例），新增题目都可以直接练习和模拟。

### 连接 OpenAI / Claude / 自建 CPA（可选）

在工作台教练面板右上角打开“教练设置”，选择通道后点“测试并启用”。测试成功才会保存并启用。两个接口通道共用同一个服务地址和 API Key，切换通道时模型会换成该通道的默认值：

- **OpenAI 兼容接口 / CPA**（支持智能体）：调用 `/v1/chat/completions`，用 `Authorization: Bearer <Key>` 认证，适合用 GPT 模型。自建的 [CLIProxyAPI（CPA）](https://router-for-me-cliproxyapi.mintlify.app/api/openai/chat) 填 `https://你的域名:8317`，**不要带 `/v1`**（带了或填成完整接口地址也会自动去掉）；API Key 填 CPA `config.yaml` 中 `api-keys` 的一项。建议点“读取接口提供的模型”，从 CPA 返回的列表里选模型（默认 `gpt-5`，以列表为准）。OpenAI 官方 API 只需填 Key，地址留空即可；也可以用环境变量 `OPENAI_BASE_URL`、`OPENAI_API_KEY`。设置里填了自己的服务地址（例如 CPA）时，不会把环境变量里的 Key 发给它，Key 必须在设置里填写。请求会先带上 `reasoning_effort`（对话 low、智能体 medium），中转或非推理模型不支持而返回 400 时，自动去掉它重试一次。
- **Claude API / CPA 中转**（支持智能体）：调用 `/v1/messages`，用 `x-api-key` 认证，地址和 Key 的填法同上，默认 `claude-opus-5-5`。也可以用环境变量 `ANTHROPIC_BASE_URL`、`ANTHROPIC_API_KEY`。请求会先带上服务端备选模型和 effort 参数，不支持而返回 400 时，自动去掉这些参数重试一次。
- **本机 Claude Code**：已安装并登录 `claude` 命令即可。面板以 `claude -p` 调用，关闭全部工具、在临时空目录运行，只生成文字，只支持对话。

连接失败或超时（约 90 秒）时，对话回复自动改用离线引导，并提示原因。地址和模型保存在 `.runtime/coach-settings.json`；Key 单独保存在本机 `.runtime/coach-secret.json`，不会返回页面，也不在导出进度中。CPA 使用 http 时页面会提醒：Key 和代码会以明文经过网络，建议配置 HTTPS。对话记录按练习轮次保存在 `solutions/.coach/`。

### 工作台智能体

教练面板的“智能体”标签页在连接 OpenAI 兼容接口或 Claude API（例如自建 CPA）后可用。两种接口用同一组工具和同样的计数规则：OpenAI 格式用 `tools` / `tool_calls` 函数调用，Claude 格式用 `tool_use` / `tool_result`。它会自己决定调用哪些工具，每一步都列在面板里：

| 工具 | 作用 | 是否计为提示 |
| --- | --- | --- |
| 运行用例 | 用你当前的代码跑内置用例，并补充最多 5 组边界用例 | 不计 |
| 对拍找反例 | 智能体写暴力解和随机小输入，在沙箱里与你的代码对比，返回最小的不一致输入 | 本地用例通过前找到反例时计 |
| 实测复杂度 | 逐级放大输入规模计时，估计增长指数，核对你写的复杂度 | 不计 |
| 草拟记录 | 草拟完成情况、错因和一句话复盘；点“填入复盘”后仍需你自己保存 | 不计 |

快捷任务有“找反例”“实测复杂度”“补边界用例”“草拟记录”，也可以直接写任务，例如“我的代码在什么输入下会超时？”。最终回复如果给出了解题方向，也会计为提示。智能体不能修改你的代码、不能直接写入进度、看不到内置参考答案；它写的代码和你的代码运行在同一个受限进程里（限时、限内存、禁止文件和网络）。每次任务最多 4 轮工具调用、合计不超过 8 次（GPT 可能在一轮里并行调用多个工具，超出的不执行），之后强制给出结论；通常需要 10～60 秒；模拟面试进行中不可用。

## 单题练习工作台

在图谱里点选题目，再点 **开始本题练习**；也可以从左侧进入 **练习工作台**。

页面顶部一条工具栏放选题、计时和保存状态。主栏自上而下是三步：① 理清问题（题意、基础用例、思路与边界、逐层提示）→ ② 写代码并验证（编辑器和测试结果在同一张卡片里）→ ③ 复盘与下次复习。教练卡片（对话 / 智能体）固定在右栏，滚动时始终可见；窗口较窄时排在代码之后。

1. 选择题目，点击开始计时，先填写核心思路和一个边界情况。
2. 在 Python 编辑区完成 `Solution` 方法。草稿会保存到本机并自动同步到项目；刷新后恢复原题和已保存的输入。
3. 点击 **运行本地用例**，查看每组输入、期望、实际结果或报错行号。可以追加 JSON 用例，基础用例始终保留。
4. 填写复杂度、一句话复盘和本次遇到的错因，再选择真实完成情况，点击 **保存结果并更新复习**。
5. 保存后返回图谱，题目状态、复习日期和主动标记的错因关系一并更新。仅运行测试不会增加完成次数。

目前覆盖已有的 46 道题、LC42 和 32 道候选新题，共 79 道题、245 组基础用例。支持数组原地修改、链表、层序树输入、LCA 节点引用，以及多种合法 BST 输出。已提供 `ListNode`、`TreeNode`、`List`、`Optional`。本地用例通过不等于平台完整判题通过，复杂度栏是用户复盘，不是自动复杂度证明。

提示需要逐层展开，看过提示后按“提示后完成”记录。**从空白开始新一轮练习**会归档旧草稿，重置计时与提示；旧测试记录不能复用为新一轮或新一天的完成。代码和测试结果保存在 `solutions/lc<题号>/`，草稿在 `solutions/.drafts/`。同题同日多次保存仍按现有规则更新当天结果，不反复累加完成次数。

运行器使用独立进程、5 秒超时、384 MB 内存限制、常用标准库白名单和受限操作检查；不执行文件、网络或外部进程操作。它面向本地本人算法代码，不作为公网多用户代码沙箱。Windows 资源控制使用 [Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)，Python 审计钩子只是限制措施的一部分，[并不是单独的安全沙箱](https://docs.python.org/3/library/sys.html#sys.addaudithook)。

## 用图谱管理学习

首页是 **知识图谱**：学习目标连接专题，专题连接题目。直接打开 http://127.0.0.1:8765/#graph 即可查看。

现在可切换 **按专题 / 按模板 / 按错因**。模板视图能看到多道题共享的解法，比如 LC230、LC501、LC530、LC538 的中序状态维护；错因视图展示有日志或主动复盘证据的关系，点节点可查原文。一个题目关联多个模板时仍只有一个题目节点，数量不会重复增加。历史错因不代表现在仍未掌握。

- **点选节点**：右侧查看完成次数、掌握状态、上次卡点和下次复习日期；可以直接记录练习或复制聊天教练指令。
- **拖动和缩放**：拖动空白处平移，拖动节点调整位置；拖动专题会带着下属题目一起移动。滚轮、缩放按钮或手机双指可调整视角，“适应画布”回到全图。
- **流态效果**：节点会柔和漂浮，曲线上有光点流动；拖动时相邻节点受弹性牵引，松手后自然回弹，平移和缩放也带有缓动。鼠标悬停或选中题目时，节点会稳住，方便阅读和点选。
- **暂停动画**：工具栏的“流动中”按钮可以暂停并记住选择。系统开启“减少动态效果”时使用静态图谱；切换到其他页面、打开记录弹窗或图谱离开可见区域时会暂停动画。
- **聚焦与折叠**：搜索题号、题名、专题或复盘文字，按专题或状态筛选。双击专题可折叠，也可使用右侧按钮；超过 6 道题的专题默认收起多余节点，点击“还有 N 道题”展开。
- **颜色提示**：绿色已掌握、蓝色待验证、黄色待复习、红色已逾期、紫色待校准、灰色待学习。复习和校准提醒优先显示，完整掌握情况在题目详情中查看。
- **布局记忆**：拖动位置、视角、筛选和折叠状态只保存在当前浏览器，不写入学习进度；点击“重新布局”可以重新排布节点。键盘可用 Tab 选节点、Enter 查看详情、`+` / `-` 缩放、`0` 适应画布。

布局保存的是你拖动后的布置，漂浮产生的小幅偏移不会写进学习记录。

连线表示已有记录中的专题归属。待学队列与学习记录中的同题只显示一次。右侧“练过的题目”统计进度表中有练习记录的题，待学题另列；折叠题目也计入总数。“今日学习”等原有清单页面仍可从左侧切换。

## 打开面板

双击 **`start-dashboard.cmd`**，浏览器会打开：

**http://127.0.0.1:8765**

也可以在项目目录运行：

```powershell
python tools/dashboard.py --open
```

需要 Python 3.9 或以上。面板运行只使用标准库，不需要安装 npm 依赖或配置 API Key。服务窗口需要保持运行，按 `Ctrl+C` 停止；只关闭浏览器不会停止服务。若端口被其他程序占用，运行 `python tools/dashboard.py --port 8766 --open`。

重复双击启动脚本会打开已经运行的面板。也可用 `python tools/dashboard.py --stop` 停止后台服务；自定义端口时同时传入 `--port`。

## 每天怎么用

1. 打开“今日学习”，选择今天的时间。面板按到期顺序排题，今天已经完成的题会计入任务量。
2. 点击“与聊天教练继续”，复制学习指令到这个项目的聊天中。教练带你解释题意、变量、手动模拟，再写代码。
3. 完成后点击“记录练习”，选择独立完成、提示后完成或暂未完成，写一句卡点。也可以让聊天教练通过脚本记录。
4. 点击“结束并保存”，追加当天题目、结果、下次复习时间和下一步到学习日志。
5. 在“复习队列”查看排期，在“题目档案”筛选状态或添加待学题，在“能力周报”查看趋势、错因和下周重点。每周在“模拟面试”完成一次限时训练。

聊天与网页共用 `learning-state.json`；聊天修改后点击刷新即可。两边同时保存时，过期页面会提示刷新，避免覆盖新记录。网页教练默认离线引导，连接 Claude 需要你在设置中手动测试并启用；页面上的练习结果来自你填写的信息和本地用例。

## 复习与记录规则

- 首次独立完成后默认 3 天再练，后续独立间隔复习按 7、21 天推进；以进度文件里的 `review_intervals_days` 为准。
- 提示后完成安排 3 天后巩固；未完成安排次日短时回忆，完成次数不增加。
- 同题同一天再次提交会更新本次结果，不能刷出多次完成。间隔不足两天的练习不能推进掌握验证。
- 待校准的旧题单独显示。日志里出现过但未进入状态表的待学题，会提示核对，避免误当新题。
- 旧状态里只有一次完成却标为 `learned` 的题，面板显示“待间隔验证”，不直接改写历史文件。
- 网页和 `coach.py status --json` 使用同一套掌握状态解释；“已掌握”和“复习到期”分开判断。旧标记保留在文件里，但不会让命令行与网页给出不同的掌握总数。
- 日志里提到但未登记的题号会提示核对；它们可能是未来计划，不会自动当成已经完成。
- 学习热力图和周报只统计状态表里可追溯的日期。已补录记录保留原练习日期和日志引用；未注明的用时或独立性不做推断。
- 写入进度和日志前保留相邻的 `.bak` 备份。相同的每日总结重复保存不会重复追加。备份是上一版，不是长期版本库。

LC11 已按 2026-10-11 的日志补为讲解后完成。LC209 以及部分早期记录仍需验证独立完成情况，可让聊天教练结合日志和下一次练习校准，不必虚填一次今天的完成。

## 常用命令

```powershell
python tools/coach.py today --minutes 120
python tools/coach.py today --minutes 90 --json
python tools/coach.py done 42 --result independent --title 接雨水 --topic 双指针 --minutes 25 --note "左右边界决定水位"
python tools/coach.py queue
python tools/coach.py weekly
python tools/coach.py weekly --markdown > weekly.md
python tools/coach.py done 199 --result hinted --title 二叉树的右视图 --topic 二叉树 --mock --minutes 28 --limit 25 --scores 4,3,4,4,2 --note "先讲清队列保存什么"
python tools/coach.py wrap --note "今天的收获" --next-action "先复习到期题"
```

`--scores` 依次是题型识别、沟通表达、代码正确性、复杂度分析、时间控制，每项 1～5 分；聊天教练的 `/algo-mock` 会用它记录评分，评分进入能力周报。

历史校准使用 `python tools/coach.py fix --help`。测试或处理副本时使用 `--state <副本路径>`，日志默认与该副本同目录，也可显式传 `--log <日志路径>`。

本次历史核对文件是 `data/history-review-2026-10-17.json`，其中包含逐条日志引用。`python tools/coach.py import-history --manifest data/history-review-2026-10-17.json` 只预览；加 `--apply` 才写入。仅补缺失题目，重复执行不会重复计数或覆盖已有记录；写入前保留 `.bak`。
