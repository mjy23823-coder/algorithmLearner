# 今日算法计划

1. 确定可用时间。用户已经说了时间（如"今天有两个小时""项目很忙"）就换算成分钟；
   没说就问一句"今天大概有多少时间？"。用户说"直接开始"则不加 `--minutes`，按画像里的每日计划时间。
2. 运行 `python tools/coach.py today --minutes <分钟>`，以脚本输出为准，不要自己重算日期。
   输出末尾有一行学习画像摘要；需要更多信息时运行 `python tools/coach.py profile`，据此调整讲解深度（见 CLAUDE.md“因材施教”）。
3. 对计划里的每道复习题，用 `rg -n "LC\\s*<题号>|LeetCode\\s*<题号>" learning-log.md` 找到上次的卡点，各浓缩成一句话。
4. 脚本给每道题写了“理由”（逾期天数、上次是否需要提示、近期错因、专题衔接、专题轮换），转述时保留关键一条，
   不要改动排序。理由不含解法要点，你也不要在用户解释之前透露思路。
   待学不足时，脚本会按学习画像自动推荐新题（标为“推荐新题”，附推荐理由），并列出“更多推荐新题”。
   用户不想做某道推荐题时用 `python tools/coach.py new skip <题号>`（7 天内不再推荐），想固定下来用 `new add`。
   待学不足时脚本还会用 1 个名额安排“校准”旧题，按实际结果记录。
5. 按以下格式输出计划（简洁，不复述大段历史）：

```text
今日计划｜<日期>｜<模式>｜约 <分钟> 分钟

1. 短时回忆（5~10 分钟）：LCxx —— 上次卡在……
2. 正式复习：LCxx —— 不看代码重写；上次卡点：……
3. 新题 / 校准：LCxx 题名（难度）—— 一句话说明为什么现在练它（取自脚本理由）
可选：……

到期但顺延：共 N 道，约 N 天消化（如有）
本周还没有限时模拟：可在面板“模拟面试”或 /algo-mock 完成（如有）
```

6. 今日已完成题目会占用今天的题量；待校准题不算新题。如果今天计划已经完成，先复盘收尾，不自动补满新题。否则计划发出后直接开始第一项。按费曼流程的第 1 步提问：请用户先说这道题是什么类型、打算怎么做，
   不要先给思路或代码。
