# 结束今日学习

1. **补全记录**：运行 `python tools/coach.py status`，对照本次会话，确认今天做过的每道题都已经用
   `coach.py done` 记录；漏记的现在补上。短时回忆不算正式练习，不用记录。
2. **下一步**：运行 `python tools/coach.py session --next-action "<一句话>"`；
   有没讲清的问题就加 `--open-question "<问题>"`，上次遗留的问题解决了就加 `--clear-questions`。
   进入新专题时加 `--topic <专题>`，并同步更新 `algorithm-roadmap.md` 的"当前进度"。
3. **写日志**：运行 `python tools/coach.py wrap --note "<今日卡点或收获>" --next-action "<下一步>"`。
   脚本自动在 `learning-log.md` 文末追加当天已记录题目、结果、复习时间和总结；相同内容重复执行不会重复写入。
   不再手工重复追加同一份总结。确需补充核心思路、复杂度或详细讲解时，在日志末尾追加独立的补充段落，可参考：

```markdown
## YYYY-MM-DD｜<今日主题>

- **LCxx 题名**：完成情况（独立 / 提示后完成 / 未完成）。核心思路一句话；复杂度。
- **复习：LCxx 题名**：结果；暴露的问题。
- **今日卡点**：最有价值的 1~2 个错误。
- **下一步**：……（下次复习日期以 `coach.py` 为准）
```

4. **回复用户**：不超过 6 行，包括今天完成了什么、最大的收获或卡点、下次最先复习哪道题以及日期。
   不重复大段历史。
